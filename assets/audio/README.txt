Este directorio debe contener los archivos de audio del juego:

- correct.mp3       ← Sonido de letra correcta (tono positivo, corto ~0.3s)
- wrong.mp3         ← Sonido de letra incorrecta (tono negativo, corto ~0.3s)
- word_complete.mp3 ← Celebración al completar palabra (~1s)
- game_over.mp3     ← Sonido de game over (~2s)
- button.mp3        ← Click de botón (muy corto ~0.1s)
- music_bg.mp3      ← Música de fondo en loop (opcional)

NOTA: Si los archivos no existen, el juego funciona sin sonido.
Para generar sonidos gratuitos, puedes usar:
  - https://freesound.org
  - https://www.zapsplat.com
  - Herramientas de generación de audio

Todos los archivos deben ser MP3, tamaño pequeño (<100KB recomendado).
